# dog-vs-cat-image-classification
Dog vs Cat Image Classification using Machine Learning and Google Teachable Machine.
🐶 Dog vs Cat Image Classification

An AI/ML project that classifies images of dogs and cats using Google Teachable Machine.

🚀 Project Demo

"Try the trained model here" (https://teachablemachine.withgoogle.com/models/6CR4fccov/)

✨ Features

- Dog vs Cat image classification
- Machine learning model trained using Google Teachable Machine
- Real-time webcam predictions
- Prediction confidence scores

🛠️ Technologies Used

- Google Teachable Machine
- TensorFlow.js
- JavaScript
- HTML

▶️ How to Use

1. Open the project demo link.
2. Allow camera access if requested.
3. Show a dog or cat image to the webcam.
4. Observe the model's prediction.

🎯 Objective

To explore image classification and understand how machine learning models can recognize different objects.
